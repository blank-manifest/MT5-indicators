# MetaTrader 5 Indicators

A free collection of compiled MetaTrader 5 indicators ready to drop in and use — no source code, no setup, just download and trade.

## How to install any indicator

1. Download the `.ex5` file from the folder below
2. Copy it to your MT5 `MQL5\Indicators\` data folder
   - In MT5: **File → Open Data Folder → MQL5 → Indicators**
3. Restart MT5 or refresh the Navigator panel
4. Drag the indicator onto any chart
